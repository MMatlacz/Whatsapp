# OpenRouter :free — official free-model API, no ban risk

Models with IDs ending in `:free` cost $0 through the official OpenRouter API with low rate limits (≈20 req/min; daily caps roughly 50–1000 vary by model; free tier includes Llama 3.3 70B, DeepSeek R1, Gemma 3). Needs an OpenRouter API key from a free account — no payment — and the human already has one in Pi's auth store. Official API, so no account-ban risk.

Provenance: [OpenRouter — API Credit & Rate Limits](https://openrouter.ai/docs/api_reference/limits), [Free Variant guide](https://openrouter.ai/docs/guides/routing/model-variants/free) (accessed 2026-09-05). Grade: ban-safe primary candidate; daily caps may throttle chat volume.
