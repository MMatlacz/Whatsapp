# LibreTranslate — self-hostable open-source translation, offline-capable

Open-source (AGPL) REST translation API powered by Argos Translate/OpenNMT. Self-hosted: keyless, no limits, offline-capable — fits a desktop app by running alongside it, zero network and no ToS exposure. The public instance at libretranslate.com currently requires an API key (bot-abuse notice on the homepage, accessed 2026-09-05). Quality below ChatGPT; direct id↔pl model coverage unverified.

Provenance: [libretranslate.com](https://libretranslate.com/), [LibreTranslate on GitHub](https://github.com/LibreTranslate/LibreTranslate) (accessed 2026-09-05). Grade: best privacy-safe fallback for a local desktop app; costs disk and a model download.
