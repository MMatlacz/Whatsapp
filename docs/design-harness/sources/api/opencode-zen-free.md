# OpenCode Zen — free models without an API key (Muse Spark, Big Pickle)

OpenCode Zen serves $0 models: Muse Spark 1.3 contributor-free (Meta; `openai-responses` endpoint at `opencode.ai/zen/v1`; the human's current Pi default model) and Big Pickle (GLM-4.6; `chat/completions`; 200k context, 32k output; reported slower). Free, no API key required for Zen free models; sources note "data may be used for training" — a privacy caveat for private chat text.

Provenance: [OpenCode Zen docs](https://opencode.ai/docs/zen/), [models.dev — OpenCode Zen](https://models.dev/providers/opencode) (accessed 2026-09-05). Grade: ban-safe, zero-setup candidate (already running in Pi); weigh the training-data caveat against chat privacy.
