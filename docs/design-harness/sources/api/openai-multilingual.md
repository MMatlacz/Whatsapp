# OpenAI API multilingual — ChatGPT translates without a separate layer

OpenAI models handle a wide range of languages: send prompts in the language you want, mix languages in input, and the model keeps context. OpenAI explicitly lists localizing an application without a separate translation layer and prototyping global features quickly as intended uses; best results come from keeping the whole prompt in one language.

Provenance: [How can I use the OpenAI API with text in different languages? — OpenAI Help Center](https://help.openai.com/en/articles/6742369-how-can-i-use-the-openai-api-with-text-in-different-languages) (accessed 2026-09-05). Grade: direct support for the translation-via-ChatGPT judgment for Polish/Indonesian text translation; audio translation via Whisper is a separate endpoint and not needed here.
