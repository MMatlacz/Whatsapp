# reverse-engineered-chatgpt — chatgpt.com backend-api without an API key

Python library (re-gpt) driving `chatgpt.com/backend-api` conversations with a session token — no API key, the same mechanism family as [Pi's Codex OAuth](../api/pi-codex-oauth.md). Unofficial: ToS violation, account-ban risk, and anti-bot drift are documented.

Provenance: [Zai-Kun/reverse-engineered-chatgpt on GitHub](https://github.com/Zai-Kun/reverse-engineered-chatgpt), [dev.to — "I Reverse Engineered ChatGPT's UI … and Here's Why You Shouldn't"](https://dev.to/gautamvhavle/i-reverse-engineered-chatgpts-ui-into-an-openai-compatible-api-and-heres-why-you-shouldnt-ch) (accessed 2026-09-05). Grade: proves the translate-via-account path is implementable; keeps the ToS risk the design already mitigates with the free-engine fallback.
