# The app supports all WhatsApp chat features

The interface covers the full chat experience: replying to messages, viewing images, seeing when a message is a reply to an earlier message, timestamps, usernames and photos. Feasibility evidence: [whatsapp-web.js media, message-replies and profile-picture support](../sources/github/whatsapp-web-js.md).
