# Translation uses a ban-safe free-model provider, not bannable account tricks

The human rejects the bannable ChatGPT backend-api path. Translation uses a chain: a free-model provider with automatic fallback across the other free models (OpenCode Zen Muse Spark / Big Pickle, OpenRouter :free) and then the keyless engines; chain order is implementation-configurable.
