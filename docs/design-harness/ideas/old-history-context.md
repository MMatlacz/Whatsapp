# Old history is persisted and used as translation context

On first Baileys pairing, request full desktop history. Persist group messages locally and load preceding messages before translating the visible window, so idioms and references keep their meaning after restart. History remains local; it is not sent to a separate history service.

Evidence: [Baileys history sync](../sources/github/baileys.md).
