# Outgoing messages are sent as typed — no automatic translation

Sending a message does not auto-translate it; the human copies text into an external translation app and pastes it back — the app does nothing for outgoing. This overturns [auto-translate to the chosen language](archive/translate-outgoing-to-chosen-language.md), archived on the human's word.
