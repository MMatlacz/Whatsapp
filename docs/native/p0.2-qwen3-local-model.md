# P0.2 Qwen3-0.6B local-model validation

Status: candidate selected; runtime and physical-device validation pending.

Parent roadmap issue: #4

## Candidate

`Qwen/Qwen3-0.6B` is the first general multilingual model to validate for the
local fallback. Its official model card describes a 0.6B-parameter model with
100+ languages and translation support, and publishes it under Apache-2.0.

The Apple-oriented MLX conversion
[`mlx-community/Qwen3-0.6B-4bit`](https://huggingface.co/mlx-community/Qwen3-0.6B-4bit)
has a 335 MB `model.safetensors` file. That is a downloadable weight size, not
peak resident memory or a measured iPhone latency result.

## Runtime decision

Use the existing `MultilingualLocalModel` seam in
`WhatsAppTranslator/TranslationEngineCore.swift`. The proposed runtime is
MLX Swift LM with the 4-bit MLX artifact. The package targets iOS 17, but the
MLX Foundation Models bridge requires iOS 27; this app currently targets iOS
26, so the first adapter must use the plain MLX APIs rather than
`LanguageModelSession`.

No MLX dependency, model weights, or Qwen adapter is bundled yet. The model is
therefore not a product feature and must not be enabled in the production
router from this document alone.

## Validation checklist

- [ ] Add a temporary MLX Swift loading/generation harness without committing
      model weights.
- [ ] Load the 4-bit artifact in Simulator and generate one Indonesian ->
      Polish result with thinking disabled.
- [ ] Add the same P0.1 fixtures, including slang, omitted subjects,
      code-switching, quoted replies, and context windows 0/3/8/16.
- [ ] On the connected physical iPhone, record cold load, warm latency,
      tokens/second, peak memory, thermal/battery impact, and offline behavior.
- [ ] Review translation quality separately from runtime availability with a
      native Polish speaker or an agreed quality rubric.
- [ ] Compare against the OPUS-MT two-step baseline and direct M2M100 control.
- [ ] Enable the local-model router only after the physical-device and quality
      gates pass; otherwise keep the explicit unavailable-model fallback.

## Current decision

Research selection: **PASS**.

App integration: **NOT RUN** — this checkout has no MLX dependency or model
runtime, and no weights were downloaded.

Physical-device acceptance: **PENDING**. Do not close issue #4 or claim
Indonesian support until the checklist above has real device evidence.
