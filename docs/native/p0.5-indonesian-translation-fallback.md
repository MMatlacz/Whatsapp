# P0.5 Indonesian translation fallback experiment

## What was added

- `TwoStepTranslationProvider` translates a source message through an explicit intermediate language. The configured path is Indonesian -> English -> Polish.
- `TwoStepTranslationEngine` adapts that pipeline to `TranslationEngineRouter`, preserving request/model provenance and typed retryable failures.
- `MultilingualLocalModel` and `LocalMultilingualModelEngine` provide a runtime-neutral seam for a licensed on-device multilingual model.
- `UnavailableMultilingualLocalModel` makes the not-installed state explicit until a model runtime and compatible weights are selected.
- The simulator diagnostics screen exposes both paths as opt-in experiments and includes a live two-hop `Translation.framework` probe.

The production router is not silently changed. A provider or local model must first report availability and return a non-empty, validated result.

## Package verification

The focused engine suite covers:

- Indonesian -> English -> Polish stage ordering;
- first-hop availability and failure short-circuiting;
- empty intermediate output failing closed;
- an unavailable local model falling back to the two-step engine;
- local-model source-text/provenance propagation; and
- prompt-only requests being rejected instead of decoded heuristically.

The focused suite passed 17 tests, and the complete Swift package suite passed 93 tests with zero failures.

## Simulator result

On the iPhone 17 Pro simulator (iOS 26.5), the diagnostics screen reported:

- Foundation Models available, 4096-token context, 23 advertised languages;
- Indonesian (`id_ID`) not advertised;
- Polish (`pl_PL`) not advertised; and
- the live two-step Apple Translation probe blocked at Indonesian -> English with `unsupportedLanguagePair`.

Therefore the two-step abstraction is ready, but Apple's installed Translation framework is not a working Indonesian first hop on this runtime. No local multilingual model weights or runtime are bundled in this checkout, so the local-model path remains an explicit seam rather than a claimed feature.
