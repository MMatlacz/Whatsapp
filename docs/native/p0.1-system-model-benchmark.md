## Purpose

This benchmark decides whether Apple's on-device `SystemLanguageModel` is viable for contextual Indonesian -> Polish WhatsApp translation.

The benchmark intentionally separates three failure modes:

1. **Model availability failure** — the system model is unavailable on the test device or region/account state.
2. **Unsupported-language/runtime failure** — the API rejects Indonesian, Polish, mixed-language, or contextual prompts.
3. **Poor translation quality** — the route runs but the output is not good enough for the product.

## How to run

1. Open `native-ios/WhatsAppTranslator.xcodeproj` in Xcode.
2. Select the `WhatsAppTranslator` target.
3. Select a physical Apple-Intelligence-capable iPhone.
4. Build and run the app.
5. Open **P0.1 SystemLanguageModel Benchmark** from the diagnostics screen.
6. Tap **Run P0.1 benchmark**.
7. Tap **Copy all results**, then paste the Markdown export from the clipboard into this document.
8. Review output quality manually and choose a decision below.

Do not close P0.1 from simulator-only results.

## Simulator control result (not a physical-device decision)

Observed on the iPhone 17 Pro simulator, iOS 26.5 (Build 23F77), with the
model available, a 4096-token context, and 23 advertised languages. Neither
`id_ID` nor `pl_PL` was advertised.

- Raw Indonesian -> English, raw Indonesian -> Polish, all contextual
  Indonesian -> Polish cases, and the English-only prompt control failed with
  `unsupportedLanguageOrLocale` / `Unsupported language.`
- English -> Polish succeeded with a natural Polish translation.
- The ASCII/Base64 envelope avoided the immediate language error, but the model
  returned unrelated fabricated JSON instead of decoding the payload.
- The full ASCII/Unicode-escape envelope hit `exceededContextWindowSize` at
  4,091 tokens out of the 4,096-token limit on the latest run.
- The smaller body-only ASCII/Unicode-escape experiment avoided the context
  overflow, but returned only an empty code-fence fragment ("``` ``` ```"),
  not a Polish translation.
- The separate iOS `Translation` framework probe reported the `id -> pl` pair
  as `unsupported` on the same simulator, so it did not provide a local
  fallback either.

These routes are therefore diagnostic experiments only; they are not a general
Indonesian fallback and must not be enabled in the product translator.
