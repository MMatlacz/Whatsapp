## Outcome

The same 32 synthetic Indonesian -> Polish fixtures were run against three
locally provisioned MLX snapshots on macOS arm64. Every model returned non-empty
text, but almost all outputs failed the meaning and/or hallucination hard gates.

The run used `mlx-swift-lm` 3.31.3 / MLX Swift 0.31.6, the functional profile
(`maxGeneratedTokens=96`, `temperature=0.7`, `top-p=0.8`, `top-k=20`, thinking
disabled), and execution environment `macos-arm64-local`. The report records
source revision `7f24e65f2d21b9a07aed78d41d93e0ef39782556`; the worktree was
dirty, so this is not yet clean-commit/review-grade provenance.

This followed the earlier pinned Qwen3-0.6B functional run. That run also
completed 32/32 macOS records, but 26/32 outputs leaked `Polish:` or `Pl:`
labels and many were malformed, mixed-language, or semantically wrong. The
separate physical-device attempt built the signed harness but was blocked
before provisioning or inference by the device's free-profile app limit; it
therefore provides no phone performance or quality evidence.

On the eight bounded-context fixtures, Gemma 3 1B and Gemma 3 270M scored
context benefit `C=0` throughout. Qwen3.5 reached only `C=1` on four and never
`C=2`. The performance numbers show that the failure is not an empty-output or
latency problem. Peak RSS values are process high-water signals from a shared
multi-candidate process, not per-model acceptance measurements.

## What the outputs show

For `Aku sudah sampai di rumah.` ("I have already arrived home"):

- Gemma 3 1B: `"Ja już jestem w domu."` — correct.
- Qwen3.5: `Widzę już w domu.` — wrong verb/meaning.
- Gemma 3 270M: emits JSON-like instructions and repeated prompt text.

Other representative failures include Qwen3.5 producing `Jestem jeszcze raz
prześladać?` for `Masa harus aku jelasin lagi?`, and Gemma 3 1B inventing
relationships in the context case `Bapak bilang Tante datang nanti.`. The raw
per-fixture records preserve every output.

## Investigation steps already completed

1. Added a candidate catalog and local-folder verifier for Gemma 3 1B, Qwen3.5
   0.8B, and Gemma 3 270M. The verifier requires a config, tokenizer, and
   SafeTensors weights; it never downloads during inference.
2. Added the multi-candidate command path and exports: `bakeoff.json`, a
   side-by-side Markdown summary, and one report plus raw result per candidate.
3. Captured the immutable snapshot revisions and primary weight checksums shown
   above. Candidate metadata remains `researchUnpinned` because a complete
   snapshot size/checksum manifest is not committed.
4. Reviewed all 96 outputs against the predeclared rubric for meaning,
   hallucination, Polish fluency, tone/preservation, and context benefit.
5. Compared prompt sizes. The production structured prompt is roughly 346--387
   tokens; a minimal direct prompt is 27--34 tokens. A full 32-fixture minimal
   Qwen run still produced malformed or untranslated examples such as `Jako już
   dojeść.`, `Wczór w ramach pory wczór.`, `Mamie, ożat, wchodzą do domu.`, and
   unchanged Indonesian `Kamu ga jadi berangkat?`.
6. Compared runtime factories for the Qwen3.5 snapshot. Its config declares
   `Qwen3_5ForConditionalGeneration` and includes a vision configuration. On the
   same fixture, LLM/current returned `Widok na mnie, w domu.`, VLM/current
   returned `Widokam na zameł w domu.`, and VLM/minimal returned `Widok na mo na
   mo.`. The VLM path changed the text but did not restore translation quality.
7. Checked decoding variance. Greedy decoding reduced variation but still gave
   incorrect Qwen text such as `Jako już jestem na domu.`. Sampling contributes
   noise but is not the root cause.
8. Separated host execution failure from model quality. Non-elevated local probes
   hit a Metal initialization crash before inference; elevated macOS runs
   completed. This is an environment issue, not evidence that the models pass.
9. Removed the temporary probe hooks from the checked-in path: the `MLXVLM`
   dependency/import, VLM factory environment switch, greedy decode environment
   switch, and prompt-profile environment switch. The canonical harness now uses
   one reproducible local `LLMModelFactory` path and the functional decode
   profile.
10. Validated the resulting package with `swift test`: all 27 tests passed.
    `git diff --check` also passed.

## Decision and next work

Reject all three candidates for contextual Indonesian -> Polish translation. Do
not add model weights, production routing, automatic downloads, or physical-
iPhone claims. Stop searching generic sub-1B chat models and open a separately
scoped specialized or distilled Indonesian <-> Polish translator experiment.
