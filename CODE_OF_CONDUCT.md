# Code of Conduct

## Our standards

This project should be a focused, respectful, and technically rigorous environment.

Expected behavior includes:

- being direct without being hostile
- giving and receiving technical feedback in good faith
- keeping discussions relevant to the project
- respecting privacy and avoiding unnecessary personal data
- being careful with security-sensitive information

Unacceptable behavior includes:

- harassment, insults, or discriminatory language
- publishing private information without permission
- posting secrets, credentials, or sensitive user data
- deliberately weakening security controls
- repeated off-topic disruption

## Enforcement

Project maintainers may edit, hide, or remove comments; close issues or pull requests; or block contributors whose behavior harms the project or its users.

Security-sensitive mistakes should be handled calmly and quickly: rotate/revoke affected credentials first, remove the material, and avoid repeating the secret in public discussion.
